# Laboratório WebGL 3D

Aplicação didática para explorar gráficos 3D no navegador com JavaScript, Vite
e Three.js usando WebGL.

## Requisitos

- Node.js 20.19+ ou 22.12+
- npm
- Navegador com suporte a WebGL

## Executar localmente

```sh
npm install
npm run dev
```

O Vite informa no terminal o endereço local para abrir no navegador.

## Build de produção

```sh
npm run build
npm run preview
```

Os arquivos de produção são gerados na pasta `dist/`.

## Etapa 1

A cena contém um cubo, iluminação, grade de referência e controles de órbita e
zoom. Os controles futuros estão reservados no painel lateral e ainda não foram
implementados.
