# Origem das texturas de imagem

Sete mapas de cor vêm do **ambientCG**, projeto mantido por Lennart Demes. O crédito segue a orientação do próprio acervo. A licença dos sete ativos é **Creative Commons CC0 1.0 Universal**. O laboratório usa apenas o arquivo de cor de cada pacote `1K-JPG`, redimensionado para 512 × 512. As imagens são servidas localmente a partir de `public/textures/`. O PNG usa uma malha de 8 × 8 quadrados e quatro quadrantes coloridos para evidenciar a repetição, o deslocamento e a orientação UV. A cor base do objeto multiplica o mapa. Uma cor clara ajuda a comparar as texturas com seus arquivos originais.
